# LiveDesk

LiveDesk is a macOS video wallpaper app. Discover reads community wallpapers from Supabase and refreshes every 20 seconds while open. New uploads appear even after you load additional pages. Use Refresh to reload the current results immediately. If Discover is unavailable, downloaded wallpapers still open from Library. Discover and Library show tiles at each video’s aspect ratio. Use the search field and Filter in Discover to find community wallpapers by title, shape, resolution, or file size. Load More checks the next page of results with the same filters. Anyone can browse and download a community wallpaper into their local Library without an account. Right-click a Library tile or open its preview menu to rename or remove the local copy. The shared upload keeps its original name and stays in Discover. Local Library index changes are serialized within the running app so simultaneous imports and downloads preserve both entries. Desktop playback creates a wallpaper window for each connected display and updates the set when displays change. LiveDesk restores the saved wallpaper and layout when it launches. Wallpaper playback stays available when the main window closes. Reopen LiveDesk from the Dock to control it. Use **Pause Wallpaper** or **Resume Wallpaper** in the bottom playback bar during the current app session. **Stop Wallpaper** closes the wallpaper windows and clears the saved selection. Install LiveDesk in `/Applications` or `~/Applications` to use **Launch at Login**. If macOS asks for approval, open System Settings → General → Login Items & Extensions.

To upload a custom video, create an account or sign in on the **Account** page, then open **Upload** and choose **Upload and Share Video**. You must give the video a name before sharing it. Uploading copies the video to this Mac and publishes it to Discover for everyone. The app warns about public sharing before opening the file picker. If network publishing fails after the local copy is saved, Upload offers **Retry Sharing** under **Waiting to share**; retries reuse the local video's cloud identity. **Your cloud uploads** lists videos published by the signed-in account on any Mac; selecting one downloads a local copy. The sidebar checks Supabase every 20 seconds and reports offline or service errors. Email confirmation is disabled in Supabase for this prototype, so signup creates a usable account immediately. Restore email verification, configure custom SMTP, and set a real confirmation redirect before public release. Supabase Auth stores registered accounts and shows their count in the project's Authentication dashboard; the app does not expose a public account count.

Open `Wallpaper.xcodeproj` in Xcode and run the Wallpaper scheme. The project targets macOS 14 or later. Community metadata is in the Supabase `public.wallpapers` table, and media is in the public `wallpapers` Storage bucket. The schema and row-level security policies are in `supabase/migrations/`. The app contains a publishable key only; it never contains a service role or secret key. Authentication sessions are kept in Keychain. Builds without a provisioned data protection Keychain entitlement use the macOS login Keychain. Use a consistent signing identity for sign-in persistence checks across rebuilds. Existing prototype users may need to sign in once after upgrading from the earlier Keychain entry. Community videos must be playable MP4, MOV, or M4V files up to 50 MB. LiveDesk checks the video before adding it to Library, including when it downloads a wallpaper from Discover.

## Set a video as your Lock Screen

Live Lock Screen requires macOS Tahoe (26) or later. Open a video from **Library**, then choose **Set as Live Lock Screen**.

The first time, LiveDesk explains the one-time folder permission. Click **Continue**. In the folder picker, keep the preselected `com.apple.wallpaper` folder and click **Allow Access**. If you navigated away, press **Shift–Command–G**, enter `~/Library/Application Support/com.apple.wallpaper`, then click **Allow Access**. LiveDesk saves that permission on this Mac, so later wallpapers do not ask again.

If LiveDesk says the Apple Aerial catalog is missing, click **Open Wallpaper Settings**, download and select one of Apple’s moving wallpapers, return to LiveDesk, and click **Set as Live Lock Screen** again. LiveDesk prepares a separate HEVC copy for the Lock Screen animation; the original stays in your Library for desktop playback. After LiveDesk confirms the video is selected, press **Control–Command–Q** to check the Lock Screen.

macOS links the Lock Screen Aerial to its system wallpaper across Spaces and displays. LiveDesk installs the video in the per-user Aerial catalog; Apple may change that private format in a future macOS release.

## Release verification

GitHub Actions builds an unsigned universal Release app for pull requests into `main`. The check verifies both architectures, the macOS 14 deployment target, and the bundled sample and icon. Use Xcode 27.2 for the same build locally.

Run these checks on the candidate build and record the macOS version, display setup, and build commit with the results.

1. With a fresh Library and no account, download a Discover wallpaper. Confirm the preview opens, then quit and reopen the app and play the downloaded video from Library.
2. Sign in with a test account, quit and reopen, and verify the session is restored. Publish a video you have permission to share. On a second Mac, confirm the account lists it under Your cloud uploads and a guest can find and download it in Discover.
3. Disconnect the test Mac from the network. Confirm the sidebar reports the connection problem and downloaded Library videos still play. Reconnect and verify Discover refreshes. In a test backend, interrupt publishing after the media upload and retry. Verify there is one catalog entry for the video.
4. Apply a wallpaper, quit and reopen, and confirm playback resumes on the desktop. Repeat with two displays, then disconnect and reconnect the external display. Verify the video remains behind desktop icons across Spaces. Pause and resume playback, then stop it and verify the wallpaper does not return after relaunch.
5. Install the candidate in Applications, apply a wallpaper, and enable **Launch at Login**. Sign out of the test macOS account and sign back in. Verify LiveDesk opens and restores the wallpaper. Disable the toggle and repeat the sign-in to verify LiveDesk stays closed. Before distributing, validate signing, notarization, and first launch on a Mac without the development build or existing app data. Test the oldest supported macOS version and both processor architectures included in the release.
6. On a fresh macOS Tahoe profile, select an Apple moving wallpaper in System Settings, open a Library video in LiveDesk, and choose **Set as Live Lock Screen**. Confirm the one-time folder picker opens at `com.apple.wallpaper`, grant access, and verify a second video can be selected without another picker. Lock the Mac with **Control–Command–Q** and confirm the chosen video visibly moves on the Lock Screen. Record the macOS version and build commit.
